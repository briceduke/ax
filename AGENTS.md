# Agent notes for ax itself

This file is for people and agents working on the ax tool repo. It is not generated by `ax compile` (this repo has no root `ax.yaml`).

## Commits

Use conventional commits. The prefixes are how versions bump; a normal `feat`/`fix` merge to `main` should release itself.

- `feat:` new user-visible behavior → minor
- `fix:` bug fix → patch
- `docs:` documentation only → no bump
- Breaking: `feat!:` / `fix!:` or a `BREAKING CHANGE:` footer → minor on 0.x. 1.0 is a later, conscious choice.

Do not use `chore` for user-facing work. The release bot may title its PR `chore:`; you should not.

```
feat: add ax doctor --require-container
fix: keep VERSION a single semver line
docs: explain how releases work
```
